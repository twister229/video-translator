Cấu hình LLM

Hướng dẫn sử dụng

Hướng dẫn cấu hình LLM API (có thể sao chép)

1. API Base URL:

  • OpenAI: https://api.openai.com/v1
  • Alibaba Cloud Bailian:https://dashscope.aliyuncs.com/compatible-mode/v1
  • DeepSeek: https://api.deepseek.com/v1

2. API Key:

  • Lấy trong bảng điều khiển của nền tảng tương ứng
  • Giữ kín, tránh để lộ

3. Tên mô hình:

  • OpenAI: gpt-3.5-turbo, gpt-4, gpt-4-turbo...
  • Alibaba Cloud: qwen-turbo, qwen-plus, qwen-max...
  • DeepSeek: deepseek-chat, deepseek-coder...

4. Gợi ý:

  • Chọn mô hình phù hợp với nhu cầu thực tế
  • Lưu ý chi phí khi gọi API
